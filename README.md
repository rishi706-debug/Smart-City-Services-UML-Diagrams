# Smart City Services Platform – UML Diagrams

This folder contains five UML-style diagrams prepared for the OOAD Lab viva.

## Diagrams
1. **Use Case Diagram** – actors (User, Business Owner, Admin) and their interactions with the platform.
2. **Class Diagram** – core classes and their attributes, operations, and relationships.
3. **Sequence Diagram** – login interaction between the user, JSP page, Servlet, MySQL database, and dashboard.
4. **Activity Diagram** – login workflow, including valid and invalid credential paths.
5. **Component Diagram** – frontend, Servlet/controller, business logic, JDBC/DAO, and MySQL layers.

## Project technology assumptions
The diagrams are based on the Smart City Services Platform structure discussed for the project: JSP, Servlets, JDBC, and MySQL. Names can be adjusted if the actual implementation uses different class, table, or page names.
